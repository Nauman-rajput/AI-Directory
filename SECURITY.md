# Security policy

## Supported version

Security fixes are applied to the current version on `main`. The directory is a static browser application with no application backend or account system.

## Report a vulnerability

Do not publish credentials, personal data or exploit details in a public issue.

Use [private vulnerability reporting](https://github.com/Nauman-rajput/AI-Directory/security/advisories/new) if GitHub makes it available for this repository. If that option is unavailable, contact the maintainer through the contact channels linked in the README to arrange private disclosure.

Include the affected component, a description of the impact, reproduction steps and a minimal example. Redact secrets and personal data from logs or screenshots.

## Scope

Reports about the directory's own code, unsafe URL handling or unexpected data exposure are relevant. A vulnerability in a linked third-party service should be reported to that service directly. Broken links and incorrect pricing belong in ordinary issues.

Favorites remain in browser local storage. Fonts and tool icons use external services; those requests are described in the README.
